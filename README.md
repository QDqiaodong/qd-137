# qd-137 热气球飞行基地地面固定支架飞行航线风力区间匹配系统

## 项目简介

热气球飞行基地地面固定支架、飞行航线与风力区间匹配系统。项目包含 Vue/Vite 前端、Spring Boot 后端、MySQL 与 Redis，已按依赖层缓存和固定端口交付链路规范整理。

## 航线支架绑定：身份核对与角色权限

「航线支架绑定」页已按角色收窄，先做身份核对再操作：

- **调度（DISPATCHER）**：可改挂任意航线的支架（绑定 / 解绑 / 试配）。
- **放飞员（LAUNCH_OPERATOR）**：只读，仅可查看自己当班航线已经挂上的支架，不能改挂，也不能访问其他航线。

后端 `/api/bindings/**` 全部接口逐请求核对身份（请求头 `X-Operator-Code` / `X-Operator-Password`），未核对返回 401，越权返回 403。身份核对接口：`POST /api/auth/verify`。

初始账号（口令经 SHA-256 存储）：

| 工号 | 口令 | 角色 | 当班航线 |
| --- | --- | --- | --- |
| DISP-001 | dispatch123 | 调度 | 全部航线 |
| OP-001 | pilot123 | 放飞员 | RTE-001、RTE-002 |
| OP-002 | pilot123 | 放飞员 | RTE-003 |
| GRD-001 | ground123 | 地勤 | 支架归位交接 |

## 支架归位交接

「支架归位交接」页服务于地勤下班与下一班接班：

- **下班登记**：本班进行中，把当天动过的地面固定支架按编号加入归位清单，逐条标明「已收回停放区（RETURNED）」或「还停在场地（ON_SITE）」，然后点「下班交接」。
- **接班拦截**：交接间隙打开本页，第一眼先看到上一班遗留、还停在场地的支架；只要还有未收回的，「开始本班」按钮禁用，后端同样返回 403 拦截。
- **收回放行**：接班地勤可直接在遗留清单上逐个标记收回；全部收回后页面提示「本班可以开始作业」，才能开始本班。

全班组同时只有一个进行中（ACTIVE）班组，交接后置为 CLOSED；同一支架同一班只能登记一次。后端接口位于 `/api/returns/**`，同样逐请求核对身份（`X-Operator-Code` / `X-Operator-Password`）。

## 放飞证照台账：整批补录/换证与到期日次序

「放飞证照台账」页把历年散落的放飞证照一次补进台账，也给已经在册的人换新证。**只有调度（DISPATCHER）能写；放飞员（LAUNCH_OPERATOR）打开页面为只读，写接口在后端逐请求拦截（403）。**

一行一条：`工号, 证号, 发证日期, 到期日期`，日期一律 `yyyy-MM-dd`。整批提交时后端逐条校验，**任一条不合格，整批回滚、一条都不落库**，并返回卡在第几条（从 1 开始）、因为什么：

- **工号对不上人**：工号在在册在职人员里查无此人（`OPERATOR_NOT_FOUND`）。
- **日期填反/非法**：不是合法 `yyyy-MM-dd`，或发证日期不早于到期日期（`DATE_FORMAT` / `DATE_ORDER`）。
- **证号撞号**：证号与库里已有记录撞（`CERT_NO_DUPLICATE_IN_DB`，同时写出**目前是谁、工号多少在用这号**），或与本批另一条撞（`CERT_NO_DUPLICATE_IN_BATCH`，写出与第几条撞）。
- **换证到期日次序**：换新证时，新证到期日必须**严格晚于这个人现在手里到期日最晚的那张证**（`RENEWAL_ORDER`）；同一人在同一批里连续换证也按前序行顺延基线。首次补录（该人此前无证）不受此限。

**单条换证走同一套校验**（`POST /api/certificates/renew` 内部包装成单元素批次），不会因为只交一条就放宽到期日次序。

**两人同时交批只许一批成功**：写台账持 Redis 全局写锁（`SET NX` + 安全释放），失败者收到 `409`「已经有调度在写台账（当前持锁：工号），本批未写入，请稍后重试」，不做任何落库。失败批不写入，关闭页面再打开，成功那批仍在台账、失败那批不会偷偷出现。

接口（均逐请求核对身份）：

| 方法 | 路径 | 权限 | 说明 |
| --- | --- | --- | --- |
| GET | `/api/certificates` | 调度/放飞员 | 台账全量（放飞员只读也能看） |
| GET | `/api/certificates/operators` | 调度/放飞员 | 在册在职人员清单 |
| POST | `/api/certificates/batch` | 仅调度 | 整批补录/换证，整批原子；失败 422 带行号/原因，锁冲突 409 |
| POST | `/api/certificates/renew` | 仅调度 | 单条换证，与批量同一套校验 |

首次启动给 OP-001、OP-002 各种子一张放飞证（`CERT-OP001-01` 到期 2025-03-31、`CERT-OP002-01` 到期 2026-06-30），便于演示换证次序与撞号定位。

## 编译与启动

```bash
cd backend
mvn compile -q

cd ../frontend
npm ci
npm run build

cd ..
docker compose up -d --build
```

Docker Compose 端口均绑定到 `127.0.0.1`，镜像基础地址通过 `.env` 中的 `DOCKER_REGISTRY` 统一控制。
